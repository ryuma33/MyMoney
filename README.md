# 💰 MyMoney – personal finance prototype

An iPhone-style personal finance app in **one HTML file** (same approach as park4u).
No install, no server: open `index.html` in a browser. Data is saved on your device (localStorage).

**Features:** transactions with search and filters · budgets with 80% / 100% alerts · bills & rent with
due-day reminders (31st → last day of short months) · roommate splits and settle up · savings goals ·
insights · light / dark theme · CSV export and backup · optional receipt photos.

Built on my first prototype, `MyMoney – Personal Finance.html`: same categories, colours and screens.
Its saved data is imported automatically on first launch.

- Open: double-click `index.html`, or use VS Code Live Server
- Try it fast: on the welcome screen tap **Try with sample data**
